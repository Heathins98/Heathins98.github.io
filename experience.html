Situation

Built for SAP service-delivery consultants, who use it across Fortune 500 customer engagements. Each engagement hands consultants raw SAP exports — SMON workload CSVs, ST03N performance data, SM13 background job logs — and the majority of engagement time was going into manual data extraction, spreadsheet wrangling and slide-building rather than analysis, repeated fresh for every customer.

Constraint

The tool had to run as a shared, browser-based service that any consultant could use without a local Office install or per-machine setup, while handling real engagement-scale exports (ST03N files up to 50,000+ rows). Because it's shared infrastructure touching different customers' data across simultaneous engagements, it needed real hardening — CSRF-protected endpoints, CSP/HSTS/X-Frame-Options headers, auth — not a personal script someone runs locally.

What was built

Four integrated tools behind a single Flask/Waitress backend, each exporting server-side to a polished PowerPoint, Word or Excel deliverable via python-pptx, python-docx and xlsxwriter — streamed to the browser and deleted from disk immediately after, so no report or raw customer data sits on the server.

SMON Analysis DashboardPPTX / DOCX

Interactive time-series charts across CPU, memory and response time, per instance and per logon group.

  • Drag-and-drop system landscape builder

Component MapperXLSX

Background Job AnalyserDOCX

Parses SM13 exports, including the DBF-variant binary format, into a KPI summary and timeline.

  • Gantt-style timeline per application server
  • Recurrence-anomaly detection

Architecture

Browser-side tools call a Flask/Waitress API behind CSRF and security-header middleware, which hands off to dedicated analysis and export engines before streaming the result back and deleting the temp file. A three-tier test pyramid (pytest for the Flask layer, Jest for JS parsing logic, Selenium for end-to-end browser flows) covers it in production.

Outcome

Deployed globally across SAP's service-delivery organisation. Consultants save roughly 8 hours a week that used to go into manual CSV processing and report-building, and a complete stakeholder-ready deck now takes under 30 seconds to generate from a raw upload, down from 2–3 hours per engagement checkpoint. The code and any customer-specific detail are proprietary; this page describes the architecture and the problem it solved, not the implementation.
